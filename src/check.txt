## ТЗ проекта EarnMeter

### Что это за приложение

Калькулятор смен для работника почасовой оплатой. Помогает понять: сколько смен нужно отработать чтобы заработать нужную сумму, и распределить эти смены по календарю.

---

### Страница 1 — Calculator

**Что делает:**
1. Пользователь вводит **целевую сумму** (сколько хочет заработать)
2. Вводит **почасовую ставку**
3. Выбирает **длительности смен** (чекбоксы: 8h, 10h, 12h, 14h, 16h)
4. Нажимает **Calculate**

**Что происходит внутри:**
- Считает `нужные часы = целевая сумма / ставка`
- Алгоритм `distributeShifts` распределяет эти часы по выбранным типам смен оптимально (минимальная переработка)
- Результат записывается в **глобальный контекст** (`ShiftContext`)

**Что показывается после расчёта:**
- Required / Planned / Overtime часы
- Инпуты где можно вручную поменять количество смен каждого типа
- Кнопка **Plan shifts** → переход на страницу Planner

---

### Страница 2 — Planner

**Что делает:**
- Показывает **календарь текущего месяца**
- Справа — **сайдбар** с остатком смен и статистикой

**Логика календаря:**
- Каждый день по умолчанию показывает `+`
- Клик на `+` → открывается **модалка** с выбором типа смены (только те у которых ещё есть остаток) и "Day off"
- После выбора — день показывает время смены (напр. `12:00–24:00`) и крестик для удаления
- Крестик → удаляет назначение и **возвращает смену** обратно в остаток

**Сайдбар:**
- Список оставшихся смен (10h × 3, 12h × 8...)
- Target — сколько часов нужно
- Actual — сколько уже назначено
- Overtime — разница (зелёный если >= 0, красный если не хватает)
